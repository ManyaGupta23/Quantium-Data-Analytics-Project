## 📌 Project Overview

This project was completed as part of the **Quantium Data Analytics Virtual Experience Program (Forage)**.

The objective was to analyze customer purchasing behaviour and evaluate the effectiveness of a retail store trial using Python. The project demonstrates data cleaning, exploratory data analysis, customer segmentation, control store selection, statistical analysis, and business recommendations.

---

## 🎯 Project Objectives

- Clean and preprocess transaction data
- Analyze customer purchasing behaviour
- Perform customer segmentation
- Extract product brands and pack sizes
- Evaluate store trial performance
- Select control stores using Pearson Correlation
- Generate business insights and recommendations

# 📈 Task 1 – Customer Analytics

### Key Findings

- Mainstream Young Singles & Couples generated the highest chip sales.
- Customers preferred 170–175g chip packs.
- Kettle, Smiths, and Pringles were the top-performing brands.
- Customer purchasing behaviour varied across life stages and affluence segments.

# 🏪 Task 2 – Store Trial Analysis

### Control Store Selection

| Trial Store | Control Store |
|-------------|---------------|
| 77 | 233 |
| 86 | 155 |
| 88 | 159 |

### Key Findings

- Store 77 demonstrated the strongest positive trial performance.
- Store 86 showed limited improvement.
- Store 88 requires further validation because the selected control store differed in sales magnitude.

# 💼 Business Recommendations

- Continue successful promotional strategies in Store 77.
- Target Mainstream Young Singles & Couples through tailored marketing campaigns.
- Prioritize high-performing brands such as Kettle, Smiths, and Pringles.
- Re-evaluate the control store selection for Store 88 before implementing wider changes.
